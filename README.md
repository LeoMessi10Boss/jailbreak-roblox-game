# Jailbreak-style Roblox game starter

This repository is a starter project for a Jailbreak-inspired Roblox game. It includes a basic city map, spawn system, money system, simple vehicle spawns, and HUD.

## Files

- `ServerScriptService/Main.server.lua` — server-side game logic
- `StarterGui/HUD.client.lua` — client-side HUD
- `README.md` — project overview and usage

## Setup

1. Open Roblox Studio.
2. Create a new place.
3. Add a `Script` to `ServerScriptService` and paste the contents of `ServerScriptService/Main.server.lua`.
4. Add a `LocalScript` to `StarterGui` and paste the contents of `StarterGui/HUD.client.lua`.
5. Press Play to test.

## Included features

- Large city-style map
- Criminal/Police role assignment
- Bank heist system
- Money leaderboard
- Vehicle spawns
- Respawn system
- HUD with money and role display
